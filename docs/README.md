# board — docs

Drag-and-drop tile board host: arranges widgets, feed posts and page sections across topbar/sidebar/body zones, with per-user layout + save-as-default persistence.

- **Source:** https://github.com/fadymondy/board
- **Reference app:** https://fadymondy.com

## Install

```bash
togo install fadymondy/board
```

The plugin self-registers on blank-import (no manual wiring). See the top-level
README for usage. This plugin was extracted from the fadymondy.com togo app as
part of turning that site into a reusable plugin suite.
